Key Features

Complete Feature Set

  • PDF Encryption & Decryption — Encrypt and decrypt PDF files with advanced cryptography algorithms
  • Bulk Processing — Bulk processing of multiple PDFs for efficiency
  • AES-256 Encryption — Supports AES-256 encryption standard for maximum security
  • RSA Encryption — Supports RSA encryption standards for public key cryptography
  • Command-Line Integration — Easy integration with command-line or API-based operations
  • Digital Signing — Enables digital signing of PDFs with secure key pairs
  • Password Protection — Seamless decryption of password-protected PDF files
  • Signature Verification — Verify authenticity of signed documents

Encryption Standards Supported

  • AES-256 — Advanced Encryption Standard with 256-bit keys (military-grade)
  • AES-192 — Advanced Encryption Standard with 192-bit keys
  • AES-128 — Advanced Encryption Standard with 128-bit keys
  • RSA-2048 — RSA encryption with 2048-bit keys
  • RSA-4096 — RSA encryption with 4096-bit keys for high-security applications
  • Triple DES — Triple Data Encryption Standard for legacy compatibility
  • Elliptic Curve Cryptography — ECC for efficient key management
  • Digital Envelopes — Secure key exchange using digital envelopes
